# Claude Code Instructions

## Rules to Follow in Every Session

1. Always read `KNOWLEDGE.md` first before making any changes to this project.

2. After completing any task, if you added, modified, or removed any module, file, or feature:
   - Update the relevant section in KNOWLEDGE.md
   - Append a new line at the top of the Changelog section:
     `YYYY-MM-DD HH:MM - [ADDED/REMOVED/MODIFIED] - what changed and why`

3. If KNOWLEDGE.md does not exist, create it immediately by scanning the full codebase before doing anything else.

4. Never skip updating KNOWLEDGE.md — it is the single source of truth for this project.
